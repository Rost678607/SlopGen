# models

**EN:** The package manager for neural weights. Nothing here is committed and nothing ever will be — the local voice alone is 2.3 GiB — so the repo ships a **declaration** (`registry.py`: id, where the files live, exact sizes, licence, the pip packages the model is useless without) and `store.py` turns a declaration into a folder on disk when the operator asks for it. `slopgen models list|install|remove|path` on the command line, a screen of its own in the TUI. Sizes are exact so the manager can promise them *before* a download starts, because 2.3 GiB is a decision and not a detail.

Two things are deliberately not delegated to a library. **The downloader**: `huggingface_hub` hung twice on this project's connection — 0.6 KB/s over a socket that was never idle long enough to trip any read timeout, with no progress and no error, forever. A read timeout cannot catch that, because bytes *are* arriving; only a rate check can. So `_stream_to` watches throughput over a sliding window, hangs up on a transfer that has gone slower than 3 KB/s, and resumes with a `Range` request from the byte it stopped at — which is also why a failed transfer keeps its partial file instead of cleaning up. **The integrity check**: there are no published checksums for every file here, and a length check alone passes on a truncated-then-padded file, but a `.safetensors` carries its own map — a JSON header naming every tensor's byte range. If the last range ends exactly at the end of the file, the payload is the length its producer meant, which is cheap and catches the failure that actually happens (a resume that stitched the ranges together wrong).

pip packages are a **separate, explicit step**: a 900 MiB torch wheel is a bigger decision than a 46 MiB model and must not ride in on one silently. `missing_packages()` asks by import rather than by asking pip, because that is the question the engine will actually ask. A stage that needs a model calls `require()`, which raises `ModelMissing` — an error whose whole point is its message, since it names the command that fixes it and is the one error an operator meets before they know the manager exists.

**RU:** Пакетный менеджер для весов нейронок. Здесь ничего не коммитится и никогда не будет — один только локальный голос весит 2,3 ГиБ, — поэтому в репозитории лежит **описание** (`registry.py`: id, где лежат файлы, точные размеры, лицензия, пакеты pip, без которых модель бесполезна), а `store.py` превращает описание в папку на диске, когда оператор попросит. В командной строке — `slopgen models list|install|remove|path`, в TUI — отдельный экран. Размеры точные, чтобы менеджер мог назвать их *до* начала загрузки: 2,3 ГиБ — это решение, а не подробность.

Две вещи намеренно не отданы библиотеке. **Загрузчик**: `huggingface_hub` дважды намертво повис на канале этого проекта — 0,6 КБ/с по сокету, который ни разу не простаивал достаточно долго, чтобы сработал read timeout, без прогресса, без ошибки, навсегда. Таймаут чтения этого не ловит, потому что байты *идут*; ловит только проверка скорости. Поэтому `_stream_to` следит за скоростью по скользящему окну, рвёт соединение, если оно упало ниже 3 КБ/с, и продолжает запросом `Range` с того байта, на котором остановилось, — потому же сорвавшаяся передача сохраняет недокачанный файл, а не убирает за собой. **Проверка целостности**: опубликованных контрольных сумм на каждый файл нет, а одна лишь проверка длины проходит и на обрезанном-и-добитом файле; зато `.safetensors` несёт собственную карту — JSON-заголовок с диапазоном байт каждого тензора. Если последний диапазон кончается ровно на конце файла, полезная нагрузка той длины, какую задумал её автор: дёшево и ловит ту поломку, которая реально случается (докачка, склеившая диапазоны неправильно).

Пакеты pip — **отдельный явный шаг**: колесо torch на 900 МиБ — решение покрупнее, чем модель на 46 МиБ, и не должно приезжать вместе с ней молча. `missing_packages()` спрашивает импортом, а не у pip, потому что именно этот вопрос задаст движок. Стадия, которой нужна модель, зовёт `require()`, поднимающий `ModelMissing` — ошибку, весь смысл которой в тексте: она называет команду, которая всё чинит, и это единственная ошибка, с которой оператор встречается раньше, чем узнаёт о существовании менеджера.
