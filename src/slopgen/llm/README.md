# llm

**EN:** `client.py` — `ChatLLM`, one client for any OpenAI-compatible provider (JSON mode); provider presets in `PROVIDERS` (deepseek, gemini, openrouter, custom), popular models in `MODEL_PRESETS`. Connections are `LLMProfile` configs (`configs/llm/*.toml`), the active one chosen by `[llm].profile`; empty fields fall back to provider defaults via `resolve_provider`. API keys live in `.env` only. With `web_search` on, `complete_json` runs a tool-calling loop (`_run_tools`) offering the real `web_search` tool from `tools.py` (keyless DuckDuckGo) — the model calls it, results are fed back, then it answers.

The rest are task-specific prompt modules, each owning one job and its output contract: `characters.py` — turn a reference photo into an appearance blurb (vision), invent missing cast fields, and compile a character into the token-dense English `visual_prompt` that gets substituted into shot prompts. `rewrite.py` — the AI edit line on breakpoints: `rewrite` reworks a list of text lines, `rewrite_scenes` reworks a whole scene list and may reorder, merge, split, add or drop scenes while carrying each one's identity. `censor.py` — rewrites profane SUBTITLE lines into harmless ones (the audio is untouched), screening by regex first so a clean video costs no request at all.

**RU:** `client.py` — `ChatLLM`, один клиент для любого OpenAI-совместимого провайдера (JSON-режим); пресеты провайдеров в `PROVIDERS` (deepseek, gemini, openrouter, custom), популярные модели в `MODEL_PRESETS`. Подключения — профили `LLMProfile` (`configs/llm/*.toml`), активный выбирается `[llm].profile`; пустые поля подменяются дефолтами провайдера через `resolve_provider`. Ключи API — только в `.env`. При включённом `web_search` `complete_json` запускает цикл tool-calling (`_run_tools`) с настоящим инструментом `web_search` из `tools.py` (бесключевой DuckDuckGo) — модель его вызывает, результаты возвращаются, затем она отвечает.

Остальные модули — промпты под конкретные задачи, каждый со своим контрактом ответа: `characters.py` — превратить фото в описание внешности (vision), придумать недостающие поля каста и скомпилировать персонажа в плотный английский `visual_prompt`, который потом подставляется в промпты кадров. `rewrite.py` — ИИ-строка на брейкпоинтах: `rewrite` переписывает список текстовых строк, `rewrite_scenes` — весь список сцен, с правом переставить, склеить, разбить, добавить и удалить, сохраняя тождество каждой. `censor.py` — переписывает матерные строки СУБТИТРОВ в безобидные (озвучка не трогается), сначала просеивая регуляркой, так что чистое видео не стоит ни одного запроса.
