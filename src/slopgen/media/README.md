# media

**EN:** `ffmpeg.py` — subprocess wrappers. Background pieces are built silent (`-an`): `make_video_part` fits a clip to a duration (with an optional seek for continuous mode and a `speed` retime used by the drama A/V fit), `make_photo_part` does Ken Burns via zoompan. `make_scene_segment` composes background + voiceover + framed foreground inserts, mapping video and audio explicitly so a source clip's own sound can never leak in. `finalize` joins the scenes with the concat *filter* (not the demuxer, which drifts), burns the ASS subtitles, mixes background music with loudnorm and stamps the ad overlay — all in one re-encode. `stretch_audio` is the atempo half of the same fit.

`stock.py` — stock providers for videos (`find_clip`) and photos (`find_image`): Pexels, Pixabay, local `assets/footage` / `assets/images`, with an on-disk cache in `state/cache/`. `generate.py` — free AI generators slotted into the same chains: `pollinations` (keyless text-to-image) and `wan` (text-to-video via HF Spaces, with LTX/AnimateDiff reserves), plus the `manual` pseudo-generator, whose clips come from the operator instead of a Space (`is_manual_model`). `MODEL_CLIP_SECONDS` gives each generator's nominal clip length, which is what the drama timeline is planned from; `key_var_for_model` / `env_keys` resolve the rotating API keys.

**RU:** `ffmpeg.py` — обвязка над subprocess. Фоновые куски собираются немыми (`-an`): `make_video_part` подгоняет клип под длительность (с необязательным сдвигом для непрерывного режима и ретаймом `speed` из подгонки звука и картинки в дораме), `make_photo_part` делает Ken Burns через zoompan. `make_scene_segment` собирает фон + озвучку + вставки в рамке, явно указывая, откуда брать видео и откуда звук, так что родное аудио клипа не просочится. `finalize` склеивает сцены concat-*фильтром* (не демуксером, тот плывёт), вжигает ASS-субтитры, подмешивает музыку с loudnorm и ставит рекламный оверлей — всё за одно перекодирование. `stretch_audio` — atempo-половина той же подгонки.

`stock.py` — сток-провайдеры видео (`find_clip`) и фото (`find_image`): Pexels, Pixabay, локальные `assets/footage` / `assets/images`, дисковый кэш в `state/cache/`. `generate.py` — бесплатные ИИ-генераторы в тех же цепочках: `pollinations` (text-to-image без ключа) и `wan` (text-to-video через HF Spaces с резервами LTX/AnimateDiff), плюс псевдогенератор `manual`, клипы которого приносит оператор, а не Space (`is_manual_model`). `MODEL_CLIP_SECONDS` задаёт номинальную длину клипа каждого генератора — от неё планируется таймлайн дорамы; `key_var_for_model` / `env_keys` достают ротируемые ключи.
