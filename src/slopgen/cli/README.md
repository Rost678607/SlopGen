# cli

**EN:** Typer-based CLI. `slopgen` with no arguments launches the TUI. A **mode** comes first and shapes the rest of the line: `slopgen info <lang> <type> [flags]` for the minute-of-info clip, `slopgen drama <lang> [flags]` for the AI drama. Parameter resolution order (info): CLI flags > preset > account defaults > global defaults; drama builds its parameters from its own flags.

Two commands reopen a run that parked itself, each straight into the screen it is waiting on: `slopgen gather [dir]` for hand-made clips, `slopgen review [dir]` for a breakpoint — omit the directory and the latest such run is found. `--resume <dir>` continues a crashed one. Also here: the `--list-*` inspectors and the console progress printer, which prints the exact command to type when a run ends parked or failed.

Two sub-apps manage things rather than run them, both reading the `ConfigStore` the top-level callback puts on `ctx.obj`. `slopgen models list|install|remove|path` is the package manager for neural weights (see `slopgen/models/`) — nothing is committed, everything is fetched, and an interrupted install resumes. `slopgen voices list|add|check|remove` is the library of cloned voices; `add` exists mostly to say no, because a clipped or hissy sample does not fail loudly — it degrades every line of every video made with it, so it is measured at the one moment when re-recording is cheap. `check` asks the strictest question of the set — does the recording say its transcript? — and needs the aligner's recognizer to answer it, so it says which model would answer rather than downloading one. Runs gained `--voice` (a catalogue id or a clone's name — one namespace), `--tts-engine`, and `--tts-source manual`, which turns the voiceover into the same hand-fed errand `--manual` already is for footage.

`slopgen loop` is the third sub-app, and unlike the other two it steers something that is already running. `--loop` on any mode hands the run to `pipeline/loop.py` — one video at a time, forever or up to `--loop-limit`, with `--topics ai|me` saying who picks each one — and the subcommands (`status`, `list`, `topic`, `source`, `limit`, `breaks`, `park`, `stop`, `go`) edit its plan file from anywhere, landing on the next video and never in the middle of one. The terminal gets a third way in that the browser cannot have: when the topics are yours and the queue is empty, a loop standing in a terminal ASKS — a line is the next topic, Enter lets the model take this one, and `!ai` / `!me` / `!limit N` / `!breaks a,b` / `!park hold|go_on` / `!set key=value` / `!show` / `!stop` change the loop without leaving it. `set` and `show` are the settings themselves: everything the run was started with — length, look, voice, cast, world, ad, account — is editable while it runs, by short name (`duration`, `style`, `fx`, `cast`, `source`) or by field name, and a value naming a config that does not exist is refused at the moment it is typed rather than by a video failing hours later.

**RU:** CLI на Typer. `slopgen` без аргументов запускает TUI. Первым идёт **режим**, он задаёт вид остальной команды: `slopgen info <язык> <тип> [флаги]` — ролик-минутка, `slopgen drama <язык> [флаги]` — ИИ-дорама. Приоритет параметров (info): флаги CLI > пресет > дефолты аккаунта > глобальные; дорама собирает параметры из своих флагов.

Две команды возвращают к застывшему прогону, сразу на тот экран, которого он ждёт: `slopgen gather [папка]` — ручные клипы, `slopgen review [папка]` — брейкпоинт; без папки берётся последний такой прогон. `--resume <папка>` продолжает оборвавшийся. Здесь же инспекторы `--list-*` и консольный принтер прогресса, который печатает готовую команду, если прогон встал или упал.

Два под-приложения не запускают прогоны, а управляют вещами, и оба читают `ConfigStore`, который верхний колбэк кладёт в `ctx.obj`. `slopgen models list|install|remove|path` — пакетный менеджер весов нейронок (см. `slopgen/models/`): в репозитории нет ничего, качается всё, а оборванная установка продолжается с места обрыва. `slopgen voices list|add|check|remove` — библиотека клонированных голосов; `add` существует главным образом ради того, чтобы отказать: клиппованный или шипящий образец не падает с ошибкой — он портит каждую реплику каждого видео, сделанного с ним, поэтому его измеряют в тот единственный момент, когда перезаписать дёшево. `check` задаёт самый строгий вопрос из набора — говорит ли запись свою расшифровку? — а чтобы на него ответить, нужен распознаватель выравнивателя, поэтому он называет нужную модель, а не скачивает её сам. У прогонов появились `--voice` (идентификатор из каталога или имя клона — одно пространство имён), `--tts-engine` и `--tts-source manual`, превращающий озвучку в такое же ручное поручение, каким для видеоряда уже был `--manual`.

`slopgen loop` — третье под-приложение, и в отличие от двух других оно управляет тем, что уже работает. `--loop` у любого режима отдаёт прогон в `pipeline/loop.py` — по ролику за раз, бесконечно или до `--loop-limit`, а `--topics ai|me` говорит, кто придумывает тему, — а подкоманды (`status`, `list`, `topic`, `source`, `limit`, `breaks`, `park`, `stop`, `go`) правят его план откуда угодно: правка попадает в следующий ролик и никогда в середину начатого. У терминала есть третий вход, которого нет у браузера: когда темы твои, а очередь пуста, цикл, стоящий в терминале, СПРАШИВАЕТ — строка становится следующей темой, Enter отдаёт этот ролик нейронке, а `!ai` / `!me` / `!limit N` / `!breaks a,b` / `!park hold|go_on` / `!set key=value` / `!show` / `!stop` меняют цикл, не выходя из него. `set` и `show` — это сами настройки: всё, с чем прогон был запущен (длина, вид, голос, каст, мир, реклама, аккаунт), правится на ходу — по короткому имени (`duration`, `style`, `fx`, `cast`, `source`) или по имени поля, — а значение, называющее несуществующий конфиг, отвергается в момент набора, а не падающим через несколько часов роликом.
