# slopgen package

**EN:** Top-level package. Subpackages: `cli` (Typer entrypoint and the parked-run commands), `tui` (Textual interface), `config` (TOML config models/loader), `llm` (one client for any OpenAI-compatible provider, plus the task-specific prompt modules), `media` (ffmpeg, stock providers, free AI generators), `pipeline` (orchestrator, checkpointing, breakpoints, the loop and the stages), `web` (the browser UI: a JSON API over the same supervisor), `bot` (the Telegram front door: a chat, and that browser UI inside it as a Mini App), `publish` (upload backends). One module sits at the top rather than in a subpackage: `share.py`, which takes named things off this machine and puts them on another one — it is about the whole of `configs/` and `assets/` at once, so it belongs to neither.

**RU:** Корневой пакет. Подпакеты: `cli` (входная точка Typer и команды для застывших прогонов), `tui` (интерфейс Textual), `config` (модели/загрузчик TOML-конфигов), `llm` (один клиент для любого OpenAI-совместимого провайдера плюс модули промптов под конкретные задачи), `media` (ffmpeg, сток-провайдеры, бесплатные ИИ-генераторы), `pipeline` (оркестратор, чекпойнты, брейкпоинты, цикл и стадии), `web` (морда в браузере: JSON-API поверх того же супервизора), `bot` (парадная в Telegram: чат и та же морда внутри него как мини-приложение), `publish` (бэкенды загрузки). Один модуль лежит наверху, а не в подпакете: `share.py` — он снимает именованные вещи с этой машины и кладёт на другую, то есть работает сразу со всем `configs/` и `assets/`, и потому не принадлежит ни одному из них.
